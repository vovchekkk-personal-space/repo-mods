## What does this mod do?

Empress Spawn Browser is a full control suite for REPO.

It gives you one in-game command hub for player powers, spawn control, world control, scene inspection, freecam, object browsing, copy-forge placement, cosmetic boxes, and tax token tools.

- Press `Insert` to open it by default.
- REPOConfig is included as a dependency, so you can click the `Mods` button on the main menu and change the menu key from `Insert` to whatever key you prefer.
- No, you do not have to suffer with one key forever like some medieval peasant.

## Main Features

### Ops Deck

This is your local power stack and quick-command room.

- Toggle `God Mode`
- Toggle `Infinite Energy`
- Toggle `Infinite Strength`
- Toggle `Sticky Boost`
- Toggle `No Aggro`
- Adjust your local speed multiplier
- Fire off quick actions fast
- Use the command deck for typed control like `strength on`, `noaggro on`, `boost 2.5`, and more

### Spawn Forge

This is the searchable spawn browser.

- Search enemies, items, valuables, and cosmetic boxes
- Cosmetic boxes have their own `Cosmetic Boxes` tab now
- Spawn what you want without digging through prefab trash
- Build test encounters fast
- Sandbox loadouts and loot setups
- Cause highly intentional chaos

### Crew Board

This is for crew recovery and player management.

- Check player state quickly
- Refill yourself
- Heal everyone
- Revive everyone
- Keep a run moving when failure starts wasting your time

### World Rail

This is for direct run control.

- Toggle No Aggro
- Despawn enemies
- Destroy enemies
- Recall valuables to the truck
- Redirect enemies to your position
- Send Tax Tokens to players running Empress Spawn Browser in the lobby

### Tax Tokens

Tax Tokens are in the `World Rail` tab.

The host can send:

- Green Tax Token
- Blue Tax Token
- Purple Tax Token
- Gold Tax Token

Tax Tokens are sent through Empress Spawn Browser. Players need Empress Spawn Browser installed to receive them. This avoids forcing tokens onto vanilla players who do not want cheated cosmetic boxes.

### Cosmetic Boxes

Cosmetic Boxes are in the `Spawn Forge` tab.

They now have their own `Cosmetic Boxes` category instead of being hidden under Valuables.

You can spawn:

- Common Cosmetic Box
- Uncommon Cosmetic Box
- Rare Cosmetic Box
- Ultra Rare Cosmetic Box

### Scene Rail

This is the heavy scene tooling tab.

- Freecam
- 3D level point graph with connected lines and live markers
- 3D mesh lines on scene objects
- 3D mesh bounds on scene objects
- Object browser
- Focus, delete, and copy tools for scene objects

## How to use it

Open Empress Spawn Browser with `Insert` by default.

REPOConfig is included as a dependency. Click the `Mods` button on the main menu, open the Empress Spawn Browser settings, and change the menu key if you do not want to use `Insert`.

- The menu locks your movement while it is open
- Empress Spawn Browser uses its own cursor while the menu is open
- Most tools are immediate: click it, use it, move on
- Copy forge uses freecam controls while you place an object

## Object Browser

The object browser lets you search live scene objects by name, path, and category.

You can use it to:

- Find objects in the level fast
- Focus the camera on an object
- Delete an object
- Copy an object into forge mode

## Copy Forge

When you press `Copy` on an object in the browser, Empress Spawn Browser enters copy forge mode.

You get:

- A live silhouette preview of where the object will be placed
- Freecam movement while placing
- Automatic return to normal once you place it or cancel it

Controls:

- `WASD` to move
- `Space` and `Ctrl` for vertical movement
- `Shift` to move faster
- Mouse wheel to change placement distance
- `Q` and `E` to rotate
- `R` and `F` to adjust height
- Left click to place
- Right click or `Esc` to cancel

## Host / Singleplayer Authority

These features are for host authority or singleplayer because they change the shared run or world state.

- Spawning items

- Spawning cosmetic boxes
- Sending Tax Tokens
- Healing everyone
- Reviving everyone
- Despawning enemies
- Destroying enemies
- Recalling valuables to the truck
- Redirecting enemies
- Deleting live world objects

If it changes the run itself, expect host authority to matter.
