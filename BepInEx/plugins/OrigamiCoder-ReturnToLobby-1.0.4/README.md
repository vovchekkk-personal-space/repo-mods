# Return to lobby

An option for Hosts to return to lobby menu with current players so that they don't need to exit to main menu and re-invite everyone.
Useful if someone disconnects early so that you can return to lobby and re-invite them without waiting to complete the level for late join.

## Features
Adds a button to the in-game menu to return to lobby menu with current players and re-opening the lobby.
Host only.
Saves if currently at shop level.

## Notes
Only Host needs the mod.
Clients will not see the button even if they have the mod.
