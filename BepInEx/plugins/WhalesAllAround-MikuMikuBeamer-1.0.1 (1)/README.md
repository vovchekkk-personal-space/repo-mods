# MikuMikuBeamer

## Overview

Beamers but more miku.

Clown beamers will now scream out "MIKU MIKU BEEEAAAAMMM" when they shoot laser beams.

Side effects may include mild burns and death.

## Installation

1. Ensure you have BepInEx installed (https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/)
2. Download this mod and extract the files into the game folder (e.g. "C:\Program Files (x86)\Steam\steamapps\common\REPO\")
3. That's it! Run the game and listen out for the next clown :)
